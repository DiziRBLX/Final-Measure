## Development Status

Final Measure is still in **early development**.

Many systems are being built and tested, and most mechanics, balance values, UI, and game content are **not final**.

## Current Focus

Development is currently focused on building the main gameplay foundation, including:

- Combat
- Movement
- Character progression
- Saving and character data
- Abilities
- Inventory and equipment
- Character creation and selection
- Enemies and AI
- World content

## Development Tracking

The GitHub Project board is used to track:

- Features
- Bugs
- Recommendations
- Balance changes
- Polish

Tasks move through:

**To Do → In Progress → Integrated**

**Integrated** means the feature or change has been added to the game and is currently working.

## Repository Purpose

This repository is for **game information and development progress only**.

It does **not** contain the game's source code, Roblox place files, or private implementation details.
