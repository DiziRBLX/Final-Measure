# Final Measure Controls

> **Final Measure is still in development. Controls are subject to change.**

This page lists the current player controls used in Final Measure.

---

## Movement

| Control | Action |
| --- | --- |
| `W A S D` | Move |
| `Space` | Jump |
| `Space` while airborne | Double Jump |
| Double-tap `W` | Sprint |
| `Ctrl` | Crouch |
| Sprint + `Ctrl` | Slide |
| Hold `T` | Charge Super Jump |
| `Shift` | Toggle Camera Lock |

---

## Combat

| Control | Action |
| --- | --- |
| `LMB` | Basic Attack |
| `RMB` | Heavy Attack |
| Tap `F` | Parry |
| Hold `F` | Block |
| `Q` | Dodge |
| `G` | Vent |

### Dodge Direction

Dodging is camera-relative.

| Input | Dodge Direction |
| --- | --- |
| `Q` | Backward |
| `Q + W` | Forward |
| `Q + A` | Left |
| `Q + S` | Backward |
| `Q + D` | Right |

Dodging can also be used while airborne.

---

## Abilities

| Control | Action |
| --- | --- |
| `1-5` | Select Hotbar Slot |
| `LMB` | Begin selected ability / QTE |
| `LMB / RMB` | QTE inputs |
| `R` | Cancel active ability / QTE |
| `C` | Recharge Tempo |

Normal weapon attacks do **not** use the QTE system.

Abilities use Tempo and timed inputs. Better execution can improve the strength of an ability.

---

## Interaction & UI

| Control | Action |
| --- | --- |
| `E` | Interact |
| `B` | Open Inventory |
| `1-5` | Hotbar Slots |
| `Shift` | Camera Lock |

---

## Current Control Notes

- Sprinting currently does not consume Stamina.
- Q performs a physical directional dodge and grants temporary invulnerability.
- Blocking and parrying use the same `F` key.
- Vent is used as an emergency escape from normal hitstun.
- Vent does not clear Guard Break.
- Super Jump strength increases while `T` is held.
- Camera Lock causes the character to face the horizontal camera direction.
- Hotbar currently uses 5 slots, but this may expand later.

---

*Controls and mechanics may change during development.*
